# Copycats+ Additions

A NeoForge 1.21.1 addon for [Copycats+](https://modrinth.com/mod/copycats-plus) that adds extra block variants.

## Blocks

| Block | Description |
|---|---|
| Copycat Vertical Slope Layer | Slope layers that mount on vertical walls via the `IN_WALL` state property |

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Copycats+ (latest for 1.21.1)

## Building

```bash
./gradlew build
```

Before building, verify the `copycats_version` in `gradle.properties` matches the latest
release at [Modrinth](https://modrinth.com/mod/copycats-plus/versions?g=1.21.1&l=neoforge).
